# SPEC: US-002 — Health Check Endpoint

---

## 1. [M] User Story

**As a** usuario,
**I want** un endpoint `/health` que devuelva el estado del servidor en JSON,
**so that** mi sistema de monitoreo (Kubernetes) sepa si está vivo.

**Bounded context:** `api` (reference: `docs/context/api.md`)

**Explicit out of scope:**
- Métricas de CPU.
- Verificación de dependencias externas (DB, Cache).

## 2. [M] Acceptance Criteria

| ID | Given (context) | When (action) | Then (observable result) |
|----|-----------------|---------------|--------------------------|
| AC-1 | El servidor está corriendo | Se realiza un GET a `/health` | Se devuelve HTTP 200 OK |
| AC-2 | El servidor está corriendo | Se realiza un GET a `/health` | El cuerpo es un JSON con `status: "ok"` |
